# jsy-tools

九数云效率工具。点击插件图标，在独立标签页打开配置页面，也可在扩展详情中打开「扩展程序选项」。所有插件功能默认关闭，在配置页按需开启。开关自动保存并同步到已打开的页面。关闭快捷上传后不再接管文件拖拽，排队文件会取消；已经开始处理的单个文件会完成当前导入流程。

## 分类汇总批量设置

1. 在插件配置页开启第一项「分类汇总批量设置」。
2. 打开分析表的「分类汇总」步骤，点击「合并上一步数据」左侧的「批量设置」。
3. 点击右侧汇总胶囊逐项勾选，或在左侧多选来源字段。进入批量模式时会带入左侧已有选择，之后增选或取消一个来源字段，也会同步勾选或取消它对应的所有已有汇总项。
4. 在「统一汇总方式」中选择一种方式，所选汇总项立即生效。菜单只列出所选字段共同支持、可直接应用的方式。「第一项」和「最后一项」默认按各自来源字段升序取值。

## 其他功能

「表数据预览」插件能力默认关闭。启用后，在左侧项目栏底部、Excel 管理上方显示项目状态卡片。项目开关默认开启；关闭后仅拦截当前项目的 `conf/analysis/operators/page` XHR 请求，返回字段表头、空行数据和已完成的分页信息，减少配置步骤期间反复加载数据的等待，不拦截保存、字段配置或其他接口，已经发送的请求不取消。每个项目只在当前页面内存中缓存最后一个被拦截的请求，重新开启时仅补发这一个，没有缓存就不补发。补发使用当前登录态，若项目、企业或账号已变化则不补发；可定位到仍对应同一请求参数的预览组件时通过原生分页回调更新界面，不把旧步骤响应灌入另一个步骤。若对应预览已卸载，仍发送缓存请求，但不强行更新当前页面。不同浏览器标签页独立控制，刷新或重新打开页面恢复开启。设置页停用能力后移除侧栏卡片、恢复正常请求并清除内存缓存。当前已通过本地 Chrome + 产品 Axios 的模拟链路校验，尚未在真实登录页面验证。

配置页可直接打开 `options.html` 查看外观预览，预览中的操作不会写入插件设置。

「自动化内嵌显示」默认关闭，可在配置页开启。适用于现有 HTTP/HTTPS 域名和端口下的 `/decision/home/project/项目标识` 及子页面；沿用原“自动化”入口，将自动化限制在右侧资源内容区，保留顶部标签和项目资源列表，不新增标签。复用原生编辑实例和保存、执行、关闭逻辑；切换资源时保留编辑状态，不自动保存。关闭能力后移除插件的布局样式。支持源码中已核对的项目内嵌宿主和方法式浮层宿主；无法识别项目内容区时在控制台报告并保留原样，不移动或重建 React 编辑器、不发送保存或执行请求。已通过定向内存检查，尚未在真实登录站点验证。

「标签页快捷关闭」默认关闭，可在配置页开启。在当前项目顶部的资源标签上右键，选择「关闭其它标签页（强行）」或「关闭其他已保存标签页」，始终保留右键目标。强行关闭不弹确认，直接丢弃其它标签的未保存修改；只关已保存则保留全部未保存标签。包含溢出区的标签，沿用原生关闭回调处理路由和视图缓存，不删除项目资源。草稿丢弃失败时停止关闭并提示；关闭能力后恢复原有右键行为。此能力依赖产品当前 React 标签结构，未识别时不接管。已通过定向内存检查，尚未在真实登录页面验证。

「快捷创建副本」默认关闭，可在配置页开启。点击左侧单个资源后，按 `Ctrl+C` 复制，再按 `Ctrl+V` 在当前项目内创建副本；支持表、FVS、故事板、指标树等项目资源，不包含分组。复制后点击画布仍可粘贴创建副本；输入框、公式编辑器和文字选区仍使用原有复制粘贴。复制记录只留在当前页面内存中，不存入插件缓存；复制时把资源名称放入普通文字剪贴板，创建副本直接响应按键，不依赖浏览器 `paste` 事件或自定义剪贴板格式。正常复制其他文字、剪切、切换窗口、停用能力或刷新页面后需重新复制，也不能跨项目、企业或账号使用。

副本沿用原生“原名称_时间戳”命名，必要时截短到 100 字符并追加重名序号。复用页面登录态与 `designer/editor/files/save-as` 创建已保存资源，再调用原生项目 `files/sort` 接口将副本插到原资源下方、同一分组内，并刷新 React Query 项目列表；原资源保持选中，位置保存到项目，刷新后保留。请求依次执行，创建时的重复粘贴不重复提交，不自动重试写请求。若副本已经创建但排序失败，明确提示检查列表并手动调整，不回退删除副本。此能力依赖当前 React 文件树与 QueryClient 结构，无法识别时在创建前停止。已在测试站点无痕窗口验证表、FVS、故事板和指标树的副本创建、紧邻插入及刷新后排序。

「项目快速切换」默认关闭，设置开关位于配置页最后。在项目页左上角的项目名称左侧显示下拉箭头，复用当前企业、当前账号的产品最近项目记录，保留原列表顺序、不限制条数；当前项目显示选中标记。选择项目时优先复用侧栏原入口，否则通过产品 Router 切换；无法识别切换入口时不强制刷新页面。关闭后移除下拉，不影响原侧栏列表。列表不额外读取浏览器历史，也不跨企业或账号混合；产品已清除的记录无法恢复。已通过模拟 DOM 的展示、导航和开关校验，真实登录页面效果尚未验证。

「企业快捷搜索」默认关闭，可在配置页开启，设置自动保存并同步到已打开的页面。在「切换企业」弹窗标题下方、企业列表上方固定显示搜索框，仅企业列表滚动；按企业名称输入即模糊筛选，忽略英文大小写。点击清空或有搜索内容时按 Esc 恢复完整列表；无匹配结果时显示提示。不保存搜索内容，重新打开弹窗时清空搜索。支持脚本匹配的 `/decision/*` 页面，不限于项目页。

最近使用的企业直接排在原列表前面，有分组时仅在各自分组内排序，不新增分组、标记或分割线；搜索结果沿用该顺序，未使用过的企业保持原有相对顺序。打开弹窗后，以页面确认的「当前所在企业」作为一次使用记录，不把单纯点击切换按钮当作切换成功。主环境脚本只从企业行的 React key 读取企业标识，插件后台将标识序列保存到 `chrome.storage.local.recentCorps` 并串行合并多标签页更新，所有账号共用，刷新和浏览器重启后保留；不保存账号、令牌或表数据。无法识别企业标识的行保留原相对顺序，不以同名企业替代标识。关闭能力后移除搜索框，恢复完整列表和原排序，停止记录但保留已有缓存。排序移动同一列表内的原始节点，不替换原生切换按钮及其回调。

同时支持 `jdydevelop.com` 及其子域名（包括 `test.jdydevelop.com`）的 `/dashboard#/` 页面，HTTP/HTTPS 均可。Chrome 匹配规则按 `/dashboard` 路径配置，不包含 `#` 后的前端路由；这些页面只加载企业搜索脚本。简道云「切换企业/团队」弹窗同时筛选“我创建的”和“我加入的”分组；无匹配结果时隐藏对应分组标题和列表，保留原有加入、创建操作。共用“企业快捷搜索”开关。

「表格样式」默认关闭，提供简洁、斑马纹、网格三种风格，以及自定义主题色和小/中/大字号（12/14/16px）。在设置页实时预览并自动保存，同一浏览器配置下所有项目共用，刷新后保留。仅改变分析表编辑页下方数据预览的表头和单元格绘制，不改变数据、列宽、导出内容或图表组件；普通背景按主题色搭配，业务标记底色保留。关闭能力恢复原渲染，样式选项仍保存。当前产品预览使用 Canvas，插件通过对应预览组件的 React 引用读取表格引擎，并在其单元格读取入口返回样式副本；产品引擎升级后可能需要适配。未识别到引擎时不会替换或重建表格。

Excel 导入不显示插件提示框、拖入遮罩、进度或结果弹层；导入在后台执行，失败详情仅写入浏览器开发者工具控制台。导入期间请勿刷新或关闭页面，以免中断处理。

最近操作快捷栏替换分析表顶部左侧的原快捷操作区域，保留原 + 菜单、动态字段、导出、更多和保存等右侧按钮。从原新增菜单或快捷按钮触发具体操作即记入最近记录，展开分类菜单不记录。最近使用的排最前，同一操作去重，不限制为五项；在原区域宽度内仅展示放得下的完整按钮，不换行、不滚动、不加「更多」。没有记录时左侧留空。当前场景不适用的操作不展示，临时不可用的沿用工具栏禁用条件。

记录存于 `chrome.storage.local`，同一浏览器配置下所有匹配的项目页面共用，刷新和浏览器重启后保留，多标签页写入由扩展后台串行合并。仅保存操作类型和显示名称，不保存表数据、项目配置或登录信息。关闭能力后恢复原工具栏，已有记录保留。

快捷按钮复用当前 QuickOperator 回调，沿用产品的步骤插入与类型转换。涉及拆表及新增分析表的操作通过原菜单触发，保留确认流程。运行时从 React Fiber 和菜单缓存读取当前操作与回调，产品结构变化时可能需要适配；识别失败时保留原工具栏，不注入无效按钮。当前已做静态检查与内存模拟，尚未在真实登录页面验证菜单捕获、步骤位置和确认弹窗。

Chrome 111+ 打开 `chrome://extensions`，开启开发者模式，选择「加载已解压的扩展程序」，加载本目录。无需构建或安装依赖。

登录九数云后打开 `/decision/home/project/项目标识`，包括其分析表等子路由，将一个或多个 `.xlsx`、`.xls`、`.xlsm` 拖入页面任意位置。扩展依次上传、解析、保存每个文件的**第一个工作表**，再添加到当前项目根目录并刷新左侧资源列表；第一行为表头，字段类型沿用服务端解析结果。首个工作表为空或解析失败时会报错，不会改选其他工作表。单文件失败不影响其余文件。

开启相应功能后，在任意 HTTP/HTTPS 域名和端口下的 `/decision/home/project/项目标识` 及其子路由自动生效，无需点击插件或连接按钮。脚本在 `/decision/*` 加载，以支持从其他页面通过站内导航进入项目；各项能力仍按项目路径判断是否生效。扩展仅申请用于保存能力开关的 `storage`，不读取 Cookie、不保存令牌或文件内容、不申请对象存储域名权限；上传使用产品返回的签名地址及页面已有跨域上传能力。重新加载扩展后，请刷新已打开的九数云页面。

最近操作按钮固定为图标在左、文字在右。`toolbar-icons.js` 复用产品 `add-combo/icons` 的多色 SVG，子操作沿用对应分类的图标，不依赖重新点击菜单来补充颜色；无多色版本的操作优先沿用当前页面图标。

仅文件拖拽会被接管；内部资源拖拽不处理。非 Excel 文件会跳过，接收到的文件拖拽会阻止浏览器直接打开文件。导入过程中请留在当前项目；切换项目、企业或账号会中止尚未执行的步骤。重复拖入同一文件会新建另一张表。

扩展在页面主环境复用 `HI.reqGet` / `HI.reqPost` 的登录态、租户与服务端校验，并检查项目编辑权限。保存后复用页面的 React Query 缓存刷新资源列表，不整页刷新。当前版本的 QueryClient 通过 React Provider 读取；若产品升级后无法定位，将在上传前报错。未兼容 `/analytics/decision` 等其他部署路径。

导入分为保存源表和添加分析表两个写入步骤。若后一步失败，已保存的源表会保留在「Excel 管理」中，可从那里继续添加。请求结果不明时不自动重试或删除源表，请先检查 Excel 管理和项目列表，避免重复导入。后端的数据同步或计算可能晚于文件创建完成。
